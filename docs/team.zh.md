# 团队与工作区

您的 RankMeFast 账户就是一个**工作区**。邀请只会授予所选网站的访问权限；选择**所有网站**时，权限涵盖当前及未来的网站。成员、角色、网站权限与邀请均在 **设置 → 团队** 中管理。

成员在您的工作区中所做的一切都计入**您的**套餐。他们自己的账户仍保留各自独立的额度。

## 角色

| 角色 | 权限 |
|------|------|
| 所有者 | 全部权限，包括账单、连接、API 密钥与账户设置 |
| 管理员 | 可操作获分配的网站，并可在自身权限范围内邀请和移除成员 |
| 成员 | 可操作获分配的网站 |

「产品操作」包括审计、排名跟踪、报告、关键词研究、外链、竞争对手、提醒及套餐内其他功能。只有所有者可以创建、删除、暂停或恢复网站。

以下内容仅归所有者所有，管理员和成员均无法使用：

- 账单：套餐、积分包、发票与客户门户
- Google Search Console 与 Analytics 连接
- API 密钥与 MCP 权限
- 数据导出与账户删除
- 白标品牌设置

如果成员在您的工作区中打开上述页面，会看到简短的「此工作区中不可用」提示。他们**自己**账户的设置始终可用，因为那属于个人，而非工作区。

团队角色与 RankMeFast 内部控制台的 Admin 角色互不相关，二者互不影响。

所有者始终占用一个席位，待处理邀请在发送时即预留席位。当前用量显示在页面顶部（例如「已使用 3 个席位中的 2 个」）。席位用尽后，邀请表单将被禁用，并出现**升级套餐**链接。

未被接受而过期的邀请会自动释放席位，但仍会留在列表中，方便您重新发送。

## 邀请成员

1. 打开 **设置 → 团队**。
2. 在**邀请成员**处输入同事的邮箱地址。
3. 选择成员或管理员，再选择**所有网站**或指定网站。
4. 点击**发送邀请**。

我们会通过邮件发送有效期七天的决策链接。邀请链接和登录凭据不会向发出邀请的所有者显示。

只有所有者可以邀请管理员。管理员只能邀请成员，且只能授予自己已有权限的网站。若邮箱尚无账户，RankMeFast 会创建临时账户并发送临时密码；接受邀请前必须更换该密码。

## 接受邀请

从邮件或通知铃打开邀请，使用受邀邮箱登录，核对角色与网站后选择**接受**。席位将由**待处理**变为**已激活**。

- 若由其他账户打开链接，RankMeFast 将返回「未找到」。令牌只能由收件地址兑换。
- 若链接已过期，请让所有者或管理员重新发送。
- 若邀请已被接受，再次打开链接会有相应提示。

您也可以选择**拒绝**。确认前不会发生任何变更。拒绝邀请绝不会删除已有账户；临时账户会在最后一条待处理邀请结束后删除。

## 在工作区之间切换

当您加入了多个工作区后，顶部栏会出现**工作区切换器**。其中先列出您自己的工作区，随后是您加入的每个工作区，并标注您在其中的角色。

选择后页面会重新加载并进入该工作区。此后，您在其中的每个网站、审计、报告与排名检查都属于该工作区，并消耗其套餐额度。您的选择会在下次登录时保留。

若要返回，请在同一菜单中选择自己的工作区。

## 重新发送待处理邀请

1. 打开 **设置 → 团队**。
2. 在待处理行打开 ⋯ 菜单。
3. 选择**重新发送邀请**。

重新发送邀请会生成新的操作链接，并立即使旧链接失效。如果账户仍是临时账户，邮件会继续使用原来的临时密码。重新发送不会更改账户密码。

## 更改成员角色

只有所有者可以更改角色或网站权限。在成员所在行选择**编辑权限**，再设置角色以及所有网站或指定网站。更改自下一次请求起生效。

您也可以更改待处理邀请的角色，新角色将在对方接受时生效。

所有权无法转移，所有者自身的角色也无法更改。

## 移除成员或撤销邀请

1. 打开 **设置 → 团队**。
2. 在该行打开 ⋯ 菜单。
3. 对已接受的成员选择**移除**，对待处理邀请选择**撤销邀请**。

访问权限在对方的下一次请求时即告终止，没有延迟，也无需退出登录。如果移除时对方正在查看您的工作区，其下一次点击将回到自己的工作区。

移除会立即释放席位，您可以马上邀请替补。对方创建的内容仍保留在工作区中，因为这些数据始终属于您；活动日志也会保留其姓名与相应操作的对应关系。

成员也可以移除自己，菜单中称为**离开工作区**。所有者无法被移除。

## 在大型团队中查找成员

成员列表提供按邮箱地址搜索的输入框，并对较长的团队分页显示。搜索与分页都不会改变席位计数，该计数始终反映整个团队。
