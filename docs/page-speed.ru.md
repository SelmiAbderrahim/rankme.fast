# Скорость страниц

Google оценивает страницы по **Core Web Vitals**. RankMeFast разделяет полевые и лабораторные измерения и показывает только данные, реально возвращённые настроенным провайдером.

## Данные реальных посетителей
Chrome UX Report собирает реальные визиты:
- **LCP**: появление главного элемента. < 2,5 с.
- **INP**: отклик на клик/касание. < 200 мс.
- **CLS**: прыжки макета. < 0,1.

Полевые данные появляются только при настроенном Google CrUX и достаточном трафике URL или источника. Рабочий провайдер DataForSEO Lighthouse даёт только лабораторные данные, поэтому поле остаётся пустым, а реальные посетители не выводятся из синтетического запуска.

## Лабораторная оценка (Lighthouse)
RankMeFast выполняет синтетический тест Lighthouse в контролируемой среде; в production этот лабораторный сигнал предоставляет DataForSEO Lighthouse Live. Это подсказка, и один запуск колеблется примерно на 10 пунктов.

## Мобильные
Мобильные измеряются отдельно. Без viewport или с мелкими кнопками попадает в **Исправить сейчас**.
