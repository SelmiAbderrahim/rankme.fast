# 使用 AI 助手

位于 [/assistant](/assistant) 的 AI 助手把你在 RankMeFast 中的对话集中在一个工作区。它会边生成边显示答案，并可使用获准的 RankMeFast 工具读取已保存的 SEO 证据或启动审计。

## 开始对话

1. 从侧边栏打开 **AI 助手**。
2. 可在发送第一条消息前选择站点。站点会为对话提供上下文；工具访问权限仍由账户设置决定。
3. 输入问题并按 **Enter**。使用 **Shift+Enter** 换行。
4. 查看实时回答。展开工具卡片可检查参数和结构化结果。
5. 选择 **停止** 可结束回答。已经生成的部分会保留在对话中。

对话会自动保存，刷新后仍然可用。如果要改用其他站点或不关联站点，请新建对话。

选定站点后，建议的问题围绕该站点；选择**不关联站点 — 通用建议**时，建议的问题则涉及你的账号和通用 SEO 问题。每个对话都以你的第一条消息命名，在能区分相似对话时会加上站点域名。要删除某个对话，请选择它旁边的垃圾桶图标并确认；选择**取消**则保留。如果回复在完成前被截断，已收到的部分会保留在对话中，并带有提示和**重试**按钮。

## 可运行的工具

助手与 RankMeFast MCP 使用同一套工具注册表。根据你的权限，它可以运行：

- `list_sites`、`get_latest_audit_report`、`list_keywords` 和 `get_rank_history`，用于读取已保存的站点与排名证据。
- `list_content_analyses` 和 `get_content_analysis`，用于读取已保存的 Content Intelligence 工作。
- `start_audit` 用于启动一次审计，`get_audit_status` 用于检查进度。

读取类工具使用已保存在 RankMeFast 中的数据，不会调用数据服务商。工具卡片会显示运行了哪个工具，[RankMeFast MCP](./rankmefast-mcp.zh.md) 列出了全部工具。`start_audit` 是唯一会产生花费的工具：它启动一次审计，并消耗你自己服务商账号中的额度。请把助手的回答当作参考，并对照所显示的证据核实重要改动。

## 权限

打开[设置 → MCP](/settings/profile?tab=mcp)，可配置助手和 MCP 客户端共同使用的账户默认权限。你可以开关每个工具、只允许指定站点，并禁止产生支出的操作。默认权限全部开放，因此在你主动限制前，现有账户会继续正常工作。

助手通过你的登录会话运行，因此只受这些账户默认权限约束。已禁用的工具不会提供给模型，被阻止的站点会显示为未找到，`start_audit` 还需要启用**允许产生支出的操作**。API 密钥范围只影响外部 MCP 客户端：密钥可以收紧账户默认权限，但不能扩大。详情请参阅 [RankMeFast MCP](./rankmefast-mcp.zh.md)。

## 消息与限制

你发送的每条消息都会开启一次流式 AI 回复，因此助手按账号限制请求频率：短时间内发送很多消息时，请稍等片刻再试。停止回复会保留已写出的内容。从聊天中启动审计与自己启动消耗相同的服务商额度。你所部署实例的运营方可通过 `CHAT_ENABLED` 关闭助手，并限制每条回复的长度。

## 故障排除

- **缺少某个工具：**请检查它在**设置 → MCP**下的开关。MCP 密钥范围不会改变已登录助手的访问权限。
- **站点不可用：**请确认对话已关联到正确的站点，且该站点在账号默认设置中被允许。
- **审计无法启动：**请启用该工具和支出类操作，并检查该站点是否已有审计正在运行。
- **请求过多：**稍等片刻后再试。
- **助手不可用：**该部署已停用 `CHAT_ENABLED`，或服务暂时不可用。请稍后重试或联系运营方。
- **流意外中断：**请使用提示上的**重试**。部分回复会保留在对话中。
