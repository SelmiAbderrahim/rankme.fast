# 本地 SEO

如果客户是通过搜索某个地点找到您的（比如“附近的水管工”“市中心的咖啡馆”），这些流量大多来自地图结果和商家资料，而不是普通的蓝色链接。本地搜索优化会追踪决定您是否出现在那里的三件事。此功能在 **Pro** 与 **Agency** 方案中提供。

## 资料准确性

如果一家商家的信息在所有出现的地方都保持一致，搜索引擎就会更信任它。RankMeFast 会检查您的**商家名称、地址和电话号码**在我们能看到的各处资料中是否一致。旧地址、多出来的电话号码或被缩短的名称这类不一致，可能会在您不知情的情况下拉低本地排名。我们会标出每一处不一致，方便您到对应的资料页修正。

## 评价与问答

我们会追踪您有多少**评价**、您的**平均评分**以及评价的新鲜程度，还有资料上公开的**问答**。持续有新评价且都得到回复，是最强的本地信号之一。如果评价停滞或连续出现低分，您会在这里尽早看到。

## 本地地图排名

对于您已经在追踪的关键词，我们还会记录您在**本地地图结果**中的位置，也就是显示在普通结果上方的那一小组商家。这与您通常的搜索排名是分开的：一个网站可能在普通结果中排名不错，却仍然没有出现在地图上。

## 一次检查的花费

一次**本地检查**会同时刷新您的资料信息、评价和问答，作为一个单位从您的方案中扣除。本地地图排名检查不单独计费，而是使用您平常的排名追踪额度。当您每月的本地检查用完后，会暂停到下次重置，或者您可以用额度充值。具体数字请参见[方案、限额与额度](./plans-limits-credits.zh.md)。
