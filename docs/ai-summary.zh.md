# AI 摘要

AI 摘要位于报告标签上方，会用您的语言写一小段说明。

## 功能
用简明的话告诉您先修什么、为什么重要。它不会增加新的发现。

## 我们发送的内容
- 审计发现的文本。
- 受影响的 URL。

不会发送 Search Console 数据、截图或账单信息。

## 不会改变审计结果
同样的输入，审计每次都给出同样的结果。摘要是审计完成后单独进行的一步，只读取审计结果。

## 重新生成
点击 **重新生成** 可再写一版，消耗一个摘要额度（参见[方案、限额与额度](./plans-limits-credits.zh.md)）。
