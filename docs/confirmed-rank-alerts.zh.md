# 确认的排名提醒

只有我们两次都看到下降，它才会变成提醒。这样一次性的小波动就不会进入您的收件箱。

## 变化如何被确认

1. 定时排名检查发现您的某个重要关键词下降了几位。
2. 我们在同一市场用新的请求再次检查这个关键词，这一步从不使用缓存结果。
3. 如果第二次检查仍显示下降，就是一次**已确认的排名变化**，这时我们才会提醒您。

## 波动与未确认的变化

- **波动**：第二次检查显示关键词已经回升。我们把记录保留在历史中，不发送提醒。
- **未确认**：因为月度额度用完或供应商出错，第二次检查没能完成。这条记录仅供参考，不会触发提醒。

三种结果都会显示在关键词的排名历史旁边。

## 观察标签

每条记录都会说明我们看到了什么、在什么时间：

- **市场**：检查时使用的国家、语言和设备。
- **窗口**：第一次和第二次检查的时间。
- **观察的新鲜度**：数据有多新。过时的数据会标为过时，不会当作实时数据显示。
- **来源**：数据来自哪个供应商服务。

## 提醒去向

已确认的排名变化会出现在[下一步行动](./next-actions.zh.md)中，并附带指向该关键词下降记录的链接。您可以在那里忽略或重新打开它，每个决定都会保留在历史中。

## 查看免费

打开提醒列表、下降记录或历史只读取已保存的数据，不会发起新的 SERP 请求，也不会消耗您方案中的任何单位。
