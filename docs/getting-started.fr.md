# Prise en main

RankMeFast vous montre dans quelle mesure votre site attire des visiteurs depuis Google et depuis les assistants IA.

## 1. Créez un compte
Inscrivez-vous par e-mail ou avec Google. Si le lien de vérification n’arrive pas dans les deux minutes, regardez dans vos spams.

## 2. Ajoutez votre site
Saisissez l’URL complète avec `https://`. Le site doit être public et répondre. Nous ne gardons que le schéma et l’hôte.

## 3. Lancez votre premier audit
Cliquez sur **Lancer votre premier audit**. Comptez une à trois minutes. Les limites mensuelles des offres payantes figurent dans [Plans, limites & crédits](./plans-limits-credits.fr.md).

## 4. Lisez les trois onglets
- **À corriger** : les problèmes auxquels Google réagit le plus vite. Commencez par là.
- **À surveiller** : des points moins urgents, ou des vérifications pour lesquelles les données manquent encore.
- **Réussis** : tout ce que votre site a validé.

Le détail est dans [Lire votre rapport d’audit](./audit-report.fr.md).

## 5. Étapes suivantes recommandées
- Connectez Google Search Console : voir [Connexion à Google Search Console](./google-search-console.fr.md).
- Ajoutez quelques mots-clés à suivre : voir [Suivi de positions](./rank-tracking.fr.md).
