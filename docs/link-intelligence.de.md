# Link Intelligence

Nutzen Sie Link Intelligence, wenn die normale Backlink-Übersicht nicht ausreicht. Sie können verweisende Domains, Ankertexte, Verläufe oder Domain-Ränge abrufen und Ihre Website mit bis zu drei Wettbewerbern vergleichen.

## Was eine Einheit abdeckt

- Jeder abgesendete Tiefenabruf verbraucht eine Einheit `link_intel_checks`.
- Eine Link-Lücken-Analyse verbraucht eine Einheit je Wettbewerber. Drei Wettbewerber bedeuten drei Einheiten.
- Die Vorschau zeigt die genaue Aufteilung, verbraucht aber nichts. Beim Bestätigen wird das Kontingent erneut geprüft.

Aktuelle Kontingente und Paketpreise finden Sie unter [Preise](./pricing.de.md). Die Tiefenwerkzeuge benötigen einen passenden Tarif; ein bereits gespeichertes Ergebnis erneut zu öffnen kostet nichts.

## Cache und Erstattungen

Ein Ergebnis aus dem Cache zählt ebenfalls. Auch eine erfolgreiche Prüfung ohne Zeilen zählt, denn sie bestätigt, dass zu diesem Zeitpunkt keine passenden Links gefunden wurden.

Scheitert die Quelle, bevor RankMeFast eine Zeile speichern konnte, wird diese Einheit genau einmal zurückgegeben. Bei mehreren Wettbewerbern wird jeder Teil einzeln abgerechnet: nützliche Ergebnisse bleiben verbraucht, ein fehlgeschlagener Teil ohne gespeicherte Daten wird erstattet. Vorschau, Abbruch der Vorschau und das Öffnen gespeicherter Ergebnisse sind kostenlos.

## Ergebnisse lesen

Tiefe Ergebnisse zeigen den Beobachtungszeitpunkt. Fehlt das Datum der ersten Sichtung, bleibt es unverfügbar und wird nicht erfunden. Lückenprozente werden aus gespeicherten Zeilen berechnet; die eingegebene Wettbewerberreihenfolge bleibt erhalten.

Die Prüfungen laufen **auf Abruf**, nicht als dauerhafte Überwachung. Starten Sie eine neue Prüfung, wenn Sie aktuellere Daten brauchen. Ein deaktiviertes Feature blockiert neue Prüfungen, gespeicherte Ergebnisse bleiben jedoch lesbar.

## Prüfung starten

Öffnen Sie den Backlinks-Bereich einer Website. Wählen Sie **Domains**, **Anker**, **Verlauf** oder **Lücke**, prüfen Sie die Verbrauchsvorschau und bestätigen Sie. Frühere Ergebnisse lassen sich aus der Laufübersicht ohne neuen Verbrauch öffnen.

Monatsgrenzen, Pakete und die Erstattungsregel stehen unter [Pläne, Limits & Credits](./plans-limits-credits.de.md).
