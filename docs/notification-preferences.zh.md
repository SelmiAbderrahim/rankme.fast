# 通知偏好

你可以选择 RankMeFast 向你发送哪些非安全类邮件。打开**设置 → 通知**（`/settings/notifications`），按需切换开关即可。

审计、排名和提醒规则的开关默认**开启**；**产品更新**默认**关闭**，只有在你开启后才会发送。更改会立即生效：下一封匹配的邮件会被跳过（若是你开启的开关，则会发送）。

## 每个开关控制的内容

- **审核完成**：当您某个站点的审核完成时发送。
- **排名下降**：当被跟踪的关键词下降且第二次检查确认时发送。
- **提醒规则**：当你自己的[提醒规则](./alerts.zh.md)触发时发送。此开关只管邮件渠道，Slack 和 webhook 的投递不受影响。
- **账单**：付款收据、付款失败提醒以及催缴通知。关闭它会停止所有账单邮件；您仍然可以在 **账单 → 发票** 中查看收据和历史发票。
- **产品更新**：偶发的欢迎信、产品动态和小贴士。

## 排名下降与提醒规则相互独立

**排名下降**邮件是内置的：当被跟踪的关键词下降且第二次检查确认下降时发送，你无需设置任何阈值。提醒规则是你在**提醒 → 规则**（`/dashboard/alerts?tab=rules`）中自己创建的规则，你可以设定阈值和提醒的去向，包括 Slack 或签名 webhook。两者互不替代：关闭**排名下降**不会影响你的提醒规则，删除所有规则也不会关闭内置邮件。

## 每周脉搏是独立的选择加入

[每周脉搏](./weekly-pulse.zh.md)摘要不受上述开关控制。每位团队成员在网站的 AI 可见性工作区中为自己按网站开启，未开启前始终关闭。

即使投递重试，每份摘要你也只会收到一次。如果您的地址无法收信，其他已订阅的团队成员仍会收到他们的那份。

## 安全类邮件无法关闭

无论上述开关的状态如何，以下邮件都会始终发送：

- 密码重置链接。
- 邮箱验证。
- 密码变更确认。

这些邮件用于保护您的账户。如果您意外收到此类邮件，请检查活跃会话，并在 **设置 → 安全** 中重置密码。
