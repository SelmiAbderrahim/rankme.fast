# 通知偏好

您可以控制 RankMeFast 向您发送的非安全类邮件。打开 **设置 → 通知**（`/settings/notifications`），切换四个开关中的任意一个。

所有开关默认处于开启状态。关闭某个开关会立即生效：下一封相应的邮件会被跳过。

## 每个开关控制的内容

- **审核完成**：当您某个站点的审核完成时发送。
- **排名下降**：当已跟踪的关键词在最近一次排名检查中丢失位置时发送。
- **账单**：付款收据、付款失败提醒以及催缴通知。关闭它会停止所有账单邮件；您仍然可以在 **账单 → 发票** 中查看收据和历史发票。
- **产品更新**：偶发的欢迎信、产品动态和小贴士。

## 每周脉搏是独立的选择加入

[每周脉搏](./weekly-pulse.zh.md)摘要不受上述开关控制。每位团队成员在网站的 AI 可见性工作区中为自己按网站开启，未开启前始终关闭。

即使投递重试，每份摘要你也只会收到一次。如果您的地址无法收信，其他已订阅的团队成员仍会收到他们的那份。

## 安全类邮件无法关闭

无论上述开关的状态如何，以下邮件都会始终发送：

- 密码重置链接。
- 邮箱验证。
- 密码变更确认。

这些邮件用于保护您的账户。如果您意外收到此类邮件，请检查活跃会话，并在 **设置 → 安全** 中重置密码。
