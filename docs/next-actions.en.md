# Next Actions

Next Actions collects everything worth doing on a site into one prioritized list, so you don't have to dig through separate reports.

## Where items come from

- Audit findings from your latest finished audit (Fix now and Watch).
- Confirmed rank changes from your tracked keywords.
- Drops in Search Console and analytics.
- Content recommendations and citation gaps from Content Intelligence.
- Signals you accepted in Audience Research.

## How the list is ordered

The same evidence always gives the same order, and there's no hidden score. Items are sorted by severity, then impact on your own data, then confidence (high, medium, low), then the number of affected pages, then effort, then the newest observation. Remaining ties are broken by a fixed ID, so items don't jump around.

## Deciding on an item

You can **Plan**, **Dismiss**, **Complete** or **Reopen** an item. Each decision is added to the item's history; nothing is overwritten or deleted.

## Dismissing a finding doesn't change the audit

If you dismiss an audit finding as a false positive, it leaves the list. The audit report itself isn't touched, and the finding stays in the report as it was found.

## Marking a finding fixed

Mark an audit finding as fixed once you've made the change. Decisions are kept per finding, so a later audit doesn't reset them. If a later audit still finds the same problem, the item is flagged as *still detected after being marked fixed* instead of quietly staying closed.

## Retest

Retest is only available for audit findings. It shows a spend preview first. Running it uses one audit from your monthly allowance, the same as starting an audit yourself.

## Reading is free

Opening the list or an item's history only reads saved data. It doesn't call a provider or use a unit.
