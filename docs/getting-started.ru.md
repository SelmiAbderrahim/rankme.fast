# Начало работы

RankMeFast показывает, насколько хорошо ваш сайт привлекает посетителей из Google и из ИИ-ассистентов.

## 1. Создайте аккаунт
Зарегистрируйтесь по email или через Google. Если ссылка для подтверждения не пришла за пару минут, проверьте папку «Спам».

## 2. Добавьте сайт
Укажите полный URL с `https://`. Сайт должен быть публичным и отвечать на запросы. Мы сохраняем только схему и хост.

## 3. Запустите первый аудит
Нажмите **Запустить первый аудит**. Это занимает от одной до трёх минут. Месячные лимиты платных тарифов указаны в разделе [Планы, лимиты и кредиты](./plans-limits-credits.ru.md).

## 4. Три вкладки отчёта
- **Исправить сейчас**: проблемы, на которые Google реагирует быстрее всего. Начните с них.
- **Наблюдать**: мелкие проблемы или проверки, для которых пока не хватает данных.
- **Пройдено**: всё, что ваш сайт уже выполняет.

Подробнее в разделе [Как читать отчёт аудита](./audit-report.ru.md).

## 5. Что сделать дальше
- Подключите Google Search Console: см. [Подключение Google Search Console](./google-search-console.ru.md).
- Добавьте несколько ключевых слов для отслеживания: см. [Отслеживание позиций](./rank-tracking.ru.md).
