# 公开测试版

RankMeFast 目前处于公开测试阶段。你可以把它用于实际工作，但在我们完善产品期间，难免会遇到一些不够完善的地方。

## 目前可用的功能

核心流程已经可用：运行网站审计、查看报告，以及长期跟踪关键词排名。套餐和计费已经上线。

## 仍在完善的部分

部分页面仍在完善中。文案和布局可能会在版本之间发生变化，你也可能遇到我们尚未发现的错误。如果发现不对劲的地方，请告诉我们。

## 报告问题

使用页面顶部测试版横幅中的 **报告问题**。源代码公开后，它会打开 GitHub 的问题反馈表单。在此之前，它会发起一封发往 support@rankme.fast 的邮件；如果你已关闭横幅，也可以直接发邮件到这个地址。

一份有用的报告包括：

- 你想做什么
- 你预期的结果，以及实际发生了什么
- 页面地址和你使用的浏览器
- 如果可以，附上一张截图

请不要包含密码、API 密钥或其他机密信息。我们会阅读每一份报告，但在测试期间无法承诺回复时间。

## 关注进展

维护者会在 X 上发布更新：[@rahim_selmi](https://x.com/rahim_selmi)。影响 RankMeFast 使用方式的变更会记录在[更新日志](./changelog.zh.md)中。
