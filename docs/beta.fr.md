# Bêta publique

RankMeFast est en bêta publique. Vous pouvez l’utiliser pour un vrai travail, mais attendez-vous à quelques imperfections pendant que nous le terminons.

## Ce qui fonctionne déjà

Les parcours essentiels fonctionnent : lancer un audit de site, lire le rapport et suivre le classement de vos mots-clés dans le temps. Les formules et la facturation sont actives.

## Ce qui reste à finir

Certains écrans sont encore en cours de finition. Les textes et la mise en page peuvent changer d’une version à l’autre, et vous pouvez tomber sur une erreur que nous n’avons pas encore vue. Si quelque chose vous semble anormal, dites-le-nous.

## Signaler un bug

Utilisez **Signaler un bug** dans le bandeau bêta en haut de la page. Une fois le code source public, ce lien ouvre un formulaire de signalement sur GitHub. En attendant, il prépare un e-mail à support@rankme.fast, une adresse que vous pouvez aussi utiliser si vous avez masqué le bandeau.

Un bon signalement indique :

- ce que vous essayiez de faire
- ce que vous attendiez, et ce qui s’est passé à la place
- l’adresse de la page et votre navigateur
- une capture d’écran, si possible

N’incluez jamais de mot de passe, de clé API ni d’autre secret. Nous lisons chaque signalement, mais nous ne pouvons pas promettre de délai de réponse pendant la bêta.
