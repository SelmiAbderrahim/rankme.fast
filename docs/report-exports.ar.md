# تنزيل التقارير ومشاركتها

يُنشئ RankMeFast نسخة ثابتة من التقرير الذي تشاهده. يحتفظ الملف ورابط المشاركة المبني على اللقطة بالفلاتر وتواريخ المصادر والتسميات واللغة والعلامة نفسها. لا يؤدي إنشاء التصدير إلى فحص مزوّد جديد ولا يستهلك أرصدة.

## تنزيل تقرير

1. افتح تقريرًا مكتملًا أو نتيجة مخزّنة.
2. حدّد النطاق الزمني أو الصفوف أو المحرك أو الجهاز أو الموقع أو الأقسام المطلوبة.
3. اختر **تنزيل أو مشاركة** ثم أحد التنسيقات المعروضة.
4. لإعادة التنزيل، افتح **التصديرات** ثم تبويب **التنزيلات**.

تعرض القائمة التنسيقات القادرة على تمثيل التقرير فقط. إذا كان النطاق كبيرًا بحيث لا يمكن تضمينه كاملًا، يرفض RankMeFast التصدير ويطلب تضييق الفلاتر أو استخدام CSV/JSON. لا تُحذف الصفوف بصمت.

## التنسيقات حسب نوع التقرير

المعرّفات التالية هي كتالوج التصدير الكامل، وتظهر أيضًا في ملفات JSON ذات الإصدارات.

| التنسيقات | أنواع التقارير |
|---|---|
| PDF وCSV وJSON | `audit.run`؛ `ranks.current`؛ `ranks.history`؛ `ranks.serp_features`؛ `google.gsc_search`؛ `google.gsc_sitemaps`؛ `google.gsc_generative_appearance`؛ `google.ga4`؛ `keyword.research_result`؛ `keyword.trends_run`؛ `keyword.ai_cluster_run`؛ `keyword.serp_cluster_run`؛ `keyword.cannibalization`؛ `backlinks.deep_run`؛ `backlinks.gap_run`؛ `backlinks.toxicity_run`؛ `competitors.organic`؛ `competitors.tech_stack`؛ `competitors.traffic_snapshot`؛ `competitors.traffic_comparison`؛ `competitors.content_run`؛ `competitors.landscape_run`؛ `actions.plan`؛ `ai.visibility`؛ `audience.research_run`؛ `brand.radar_scan`؛ `content.inventory_run`؛ `internal_links.run`؛ `local.seo_snapshot`؛ `local.reviews`؛ `local.geogrid_scan`؛ `pages.performance`؛ `app.keyword_tracking`؛ `app.research_result` |
| PDF وJSON | `client.composite`؛ `backlinks.summary`؛ `content.recommendation_outcome`؛ `weekly_pulse.run` |
| PDF وJSON وMarkdown | `content.analysis`؛ `content.brief` |
| CSV وJSON | `backlinks.inventory`؛ `content.monitor_feed` |
| JSON وJSON-LD | `schema.generation` |
| نص عادي | `backlinks.disavow` |

PDF للقراءة والعرض، وCSV للبيانات الجدولية فعلًا، وJSON للمستند الكامل القابل للمعالجة. تظهر Markdown وJSON-LD ونصوص التنصّل فقط عندما تكون المخرَج الطبيعي.

## الفلاتر والنطاقات وتواريخ المصادر

تسجّل اللقطة الاختيار الحالي. مثلًا، يحفظ سجل الترتيب الكلمات المختارة والنطاق الزمني، ويحفظ تقرير المراجعات المصدر والتقييم والاستعلام والتواريخ. يتضمن كل تنسيق تاريخ الرصد أو نطاقه، مع تمييز الرصد والقيم المشتقة والتقديرات والنص المولّد. لا يغيّر تعديل الشاشة لقطة موجودة.

## العلامة والهوية البيضاء

تستخدم ملفات PDF والعروض العامة علامة RankMeFast افتراضيًا. يمكن للحساب الذي يملك أصلًا صلاحية PDF بالهوية البيضاء اختيار اسم الشركة واللون والشعار المحفوظ. لا تحمل CSV وJSON وMarkdown وJSON-LD والنص علامة مرئية، لكنها تحتفظ بوضع العلامة في البيانات الوصفية. لا يمنح التصدير صلاحية جديدة للخطة.

## روابط المشاركة

إذا سمح نوع التقرير بالمشاركة، اختر **مشاركة** وحدد التنسيقات العامة المسموحة ومدة من يوم إلى 90 يومًا. المدة الافتراضية 30 يومًا ولا يمكن للرابط تجاوز انتهاء اللقطة. انسخ الرابط عند ظهوره؛ لا يخزّن RankMeFast الرابط المقروء لعرضه لاحقًا.

يمكن لأي شخص لديه الرابط فتحه من دون تسجيل دخول. تحمل الصفحة تعليمات noindex وno-store، لكن يجب مع ذلك اختيار المستلمين بعناية. استخدم **التصديرات ← المشاركات** لإبطال الرابط فورًا. تعيد الروابط المنتهية أو الملغاة أو المرتبطة بمصدر محذوف استجابة «غير موجود» نفسها.

## الخصوصية والاستخدام الخارجي

قد تحتوي الصادرات على روابط الموقع وعبارات البحث والمقتطفات والترتيب ونصوص المراجعات وتحليلات الطرف الأول وعلامة العميل. شاركها فقط مع المصرّح لهم برؤية التقرير الأصلي. يخزّن RankMeFast اللقطة المسموح بها وبصمة محتواها، ولا يخزّن بيانات اعتماد المزوّد أو ملفات الارتباط أو رموز المشاركة الخام أو حمولة الفوترة. تنتهي اللقطات بعد 90 يومًا ويُمنع الوصول فور حذف الموقع أو الحساب، ثم يتم الحذف المادي وفق الاحتفاظ.

ملفات CSV بترميز UTF-8. تُعامل الخلايا التي تبدأ بعلامة صيغة (`=` أو `+` أو `-` أو `@` أو tab أو carriage return، حتى بعد مسافات) كنص قبل تطبيق اقتباس CSV. لا تحذف بادئة الحماية في Excel أو Sheets.

يستخدم JSON حاليًا `schemaVersion: 1` مع `kindVersion` خاص بنوع التقرير. اقرأ الحقلين وارفض الإصدارات التي لا يفهمها تكاملك، ولا تعتمد على معرّفات قاعدة البيانات الداخلية أو اسم الملف.

يجب أن يراجع شخصٌ ملفات التنصّل وMarkdown وJSON-LD قبل استخدامها. لا يرسل RankMeFast ملف التنصّل إلى Google، ولا ينشر Markdown، ولا ينشر JSON-LD نيابة عنك.
