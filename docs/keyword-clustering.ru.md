# Кластеризация запросов

Кластеризация группирует отслеживаемые запросы по числу общих URL в выдаче. Она работает только с наблюдениями SERP, которые RankMeFast уже сохранил, и никогда не запускает проверку позиции, чтобы восполнить пробел.

## Как складывается кластер

1. Для каждого запроса RankMeFast берёт 10 верхних URL из его последнего сохранённого наблюдения.
2. Два запроса связываются, если у них не меньше 3 общих URL.
3. Связи выстраиваются в цепочки: если A связан с B, а B с C, все три попадают в один кластер.

Один запуск охватывает до 200 запросов. Состав кластеров определяется простой арифметикой общих URL, поэтому одни и те же сохранённые наблюдения всегда дают одни и те же кластеры.

## Какие запросы участвуют

Участвуют только запросы Google с наблюдением за последние 7 дней. Перед запуском предварительная проверка показывает, какие из них подходят.

Запросы, которые не могут участвовать, перечисляются с причиной (отсутствует, устарело или пусто), а не пропадают молча. Запуск расходует единицу с момента старта, и за заблокированные запросы она не возвращается.

## Названия

ИИ-среда может предложить название для каждого кластера, оно помечается маркером ИИ. Если с названиями не получилось, кластеры останутся без имён. Сама группировка от этого не меняется, потому что никогда не зависит от модели.

Три общих URL означают порог, а не степень схожести, и кластер ничего не говорит о поисковом намерении. RankMeFast никогда не выдумывает запрос, URL или наблюдение, чтобы дополнить группу.

## Тарифы и доступность

Месячные лимиты по тарифам:

- Starter: 0
- Pro: 4
- Agency: 20

Оператор может отключить кластеризацию флагом `KEYWORD_CLUSTERING_ENABLED`. Тогда новые запуски отклоняются с локализованным сообщением, а уже готовые кластеры остаются доступны. Как устроены единицы, объясняет раздел [Цены](./pricing.ru.md).
