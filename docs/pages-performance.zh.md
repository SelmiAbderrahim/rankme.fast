# 页面表现

打开一个站点并选择 **页面**，即可把搜索表现与最近一次抓取清单放在一起查看。打开标签时只读取已存数据。只有选择 **刷新** 或 **收集备用数据** 才会开始新的收集。

## 数据来源

如果已连接的 Google Search Console 资源覆盖该站点，RankMeFast 会优先使用它。首次同步期间或所选时间窗没有记录时，Search Console 仍是主要来源。可用但为空的 Search Console 数据不会被备用估算替换。

如果 Search Console 未连接、需要重新连接、已撤销或资源不匹配，页面标签可以读取最近保存的排名关键词快照。来源标签会区分 DataForSEO 与演示数据。如果两种来源都没有已存数据，页面会说明下一步操作。

## 指标和时间窗

Search Console 的点击、展示、CTR 和平均排名是 7、28 或 90 天滚动窗口内的观测指标。Google 报告有三天延迟。Search Console 可能抽样或限制返回行数，因此比较总量前应查看覆盖说明。

备用来源的排名、搜索量、难度、排名关键词数和预估流量来自一个时间点的快照。点击、展示和 CTR 会显示 **不可用**，这与真实的零值不同。切换时间窗只会改变历史与比较范围，不会改变快照的主要指标。

**自上次同步以来** 比较当前成功快照与前一个符合条件的成功快照，并不是前后周期比较。打开页面详情可查看关联的 Search Console 查询或备用关键词，以及最多 90 个已存趋势点。

## 机会与抓取信息

- **接近提升区间** 表示排名高于 3 且不超过 20，并达到需求阈值。
- **CTR 偏低** 只适用于达到展示量和排名阈值的 Search Console 记录。
- **下降** 和 **上升** 会与上一次成功同步比较排名或观测点击。
- **可见但抓取判定不可索引** 表示存在搜索表现，但最近一次 RankMeFast 抓取把页面标为不可索引。
- **未测量** 表示抓取发现了可索引页面，但当前表现来源没有对应记录。

抓取可索引性只描述 RankMeFast 抓取时看到的状态，不能证明 Google 已将 URL 编入索引。来源可见但不可索引的页面会保留在列表中，便于排查冲突。

## 刷新成本与过期数据

Search Console 刷新复用现有同步，不消耗关键词查询。备用刷新消耗一次关键词查询，即使命中缓存也会计数。打开详情、搜索、筛选、排序、切换每页数量和翻页都只是读取已存数据，不消耗用量。

如果刷新失败，最近一次成功快照会继续显示并标为过期。备用快照超过排名关键词缓存的新鲜度窗口后也会变为过期。

## 删除与导出

删除站点或完成账户删除请求后，已存的页面快照会被移除。当前账户导出不包含页面快照，也不包含 GSC 和排名追踪的时间序列历史，因此不能把该导出当作这些趋势的备份。

## 故障排查

- 显示 **同步中** 时，请等待首次 Search Console 收集完成。
- 显示 **重新连接** 时，请在 Google 标签恢复连接。
- 资源不匹配时，请选择覆盖正确 URL 前缀或域名的资源。
- 没有已存来源时，请连接 Search Console 或明确启动计费的备用收集。
- 达到上限时，请检查关键词查询用量或套餐。已有快照仍可读取。
- 数据不可用时，请重试同一来源。RankMeFast 不会悄悄离开可用的 Search Console 来源。
