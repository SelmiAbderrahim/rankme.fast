# Audience Research

Audience Research turns your market, a few seed topics, and optional competitor domains into audience segments, using only public evidence.

## What you provide

- Your site's market (country and language).
- Up to ten seed topics you want to explore.
- Up to five competitor domains (optional).

## Preview before you spend

The preview shows what a run will use and how many runs you have left this month. Previewing is free and reserves nothing.

## What a run costs

One run consumes one `audience_research_runs` unit, no matter how many pages it reads inside. Monthly runs per plan: Starter 2, Pro 10, Agency 30. There's no credit pack for this metric. When you reach the cap, wait for the monthly reset or upgrade.

Starting the same run twice only charges once: the second start returns the run that's already going. A later fresh run is a new run and uses a new unit.

## A cost limit on every run

Every run has a fixed cost limit, with a tighter limit for the AI clustering step. A run that hits the limit stops early, keeps the evidence it already collected, and is labeled **partial results**.

## How pages are selected

The same inputs always pick the same public pages. We rank candidates by topic relevance, then search position, then recency, and spread picks across source types and domains so no single site can dominate the evidence.

## Run states

A run moves through **queued → discovering → selecting → collecting → clustering** and ends as **completed**, **partial results**, or **failed**.

## Refunds

You get the unit back, once, only when a run fails without finding any usable public evidence. Completed and partial runs keep their unit.

## Nothing is published

Results stay in your account. A run doesn't publish, post, or share anything.

## Where results go

Signals you accept appear in [Next Actions](./next-actions.en.md) and can create Content Intelligence briefs. Nothing happens until you decide.
