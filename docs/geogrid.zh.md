# 本地网格排名跟踪

一次网格扫描会从某个位置周围的多个点同时检查本地组合。这样你能看到可见度在整个街区内如何变化，而不只是某一个点的情况。

<!-- docs-truth: metric=geogrid_scans; unit=one-grid-scan-up-to-49-cells; cache-hits=count; refund=all-cell-failure-only; cadence=on-demand; estimates=provider-observation -->

## 发起扫描

选择网格大小（3×3、5×5 或 7×7）、间距和缩放级别。RankMeFast 为每个单元格执行一次 Maps 检查，整个网格算作一次计费扫描。

每个单元格会保存观测到的位次、当时本地组合的大小以及检查时间。结果以热力网格显示，旁边始终附有无障碍表格。

## 如何解读单元格

每个单元格只会是以下三种之一：

- 观测到的位次
- "不在本地组合中"
- 检查失败：不保存位次，也不会被画成排名

每个单元格都有自己的采集时间。网格是一组时间相近的检查，而不是整片区域在同一瞬间的快照。

## 用量与退还

只要至少有一个单元格可用，这次扫描就会消耗单位。只有全部单元格都失败才会退还，因为部分网格仍包含可用的观测。

## 选择中心

**网格中心**选择器默认从**我的商家**开始，也就是[本地 SEO](./local-seo.zh.md) 中与站点商家一起保存的位置。使用它不产生任何花费；如果没有已保存的商家，选择器会引导你去设置本地 SEO。**搜索地点**可按商家名称或街道地址查找，每次搜索会向你的本地列表服务商请求一次，选中结果只会填入中心，不会更改你在本地 SEO 中的商家。**输入坐标**是高级选项，上次扫描的中心只需一次点击（**使用上次扫描的中心**）。间距可选预设距离，也可自定义以公里为单位的距离。

## 限制

没有可点击的交互式地图，因为 RankMeFast 不使用地图瓦片服务商。

网格展示的是供应商在当时从这些坐标看到的结果。它不是预测，也不代表某位具体搜索者会看到什么。
