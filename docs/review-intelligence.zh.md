# 评论洞察

评论洞察会把已配置的 Google、Trustpilot 和 Tripadvisor 商家页面中的公开评论集中保存在一处。它会计算评分统计，也可以把反复出现的赞扬和投诉归纳成主题，每个主题都会引用其依据的已存储评论。

## 了解一个单位包含什么

每次确认同步使用一个 `review_syncs` 单位，覆盖整个任务。你可以选择一到三个已配置来源，并选择每个来源最多 100 条评论的深度；来源越多也不会多扣单位。主题分析包含在内。

预览或取消预览不会产生用量。当前月度限额和用量包价格请查看[定价](./pricing.zh.md)。

## 了解缓存、去重和退还规则

缓存中的公开评论仍会计入。RankMeFast 按来源和评论 ID 去重，因此成功但没有新增行的同步也会计入：数据源已经完成检查。

只有当**所有已选来源**都失败、且没有保存任何新评论时，单位才会退还，而且只退一次。部分同步、成功但没有新评论的同步，或主题生成失败，仍会消耗单位，因为评论工作已经执行或已有评论被保存。重试不会让同一个单位退还两次。

## 阅读主题和统计

评分、数量、来源分布和月度趋势都来自已存储评论行。生成的主题是可选内容，只有引用已存储评论时才会显示；无法找到依据的主题文字会被丢弃。即使主题生成失败，评论和统计仍然可用。

搜索、筛选、打开已存储运行和导出匹配 CSV 都不会使用新的同步单位。评论内容始终以纯文本显示。

## 自己决定同步时间

评论洞察是**按需运行**。它不会持续监控商家页面、发送评论提醒、回复评论或起草回复。需要更新清单时请重新同步。暂停新同步不会隐藏已存储数据。

打开网站的**评论**标签，至少配置一个来源，查看用量预览后确认。限额和退还规则请参阅[方案、限额与额度](./plans-limits-credits.zh.md)。
