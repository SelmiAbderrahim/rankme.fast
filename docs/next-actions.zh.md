# 下一步行动

下一步行动把网站上值得做的事汇总成一份按优先级排序的清单，您不必在各个报告之间来回查找。

## 条目从哪里来

- 最近一次完成的审计中的发现（立即修复与观察）。
- 已跟踪关键词中已确认的排名变化。
- Search Console 与分析数据中的下滑。
- 来自 Content Intelligence 的内容建议与引用缺口。
- 您在受众研究中接受的信号。

## 清单如何排序

同样的数据总是得到同样的顺序，没有隐藏评分。我们依次按严重程度、对您自有数据的影响、置信度（高、中、低）、受影响页面数、工作量和最新观察时间排序。仍然并列时，用一个固定标识符决定先后，所以条目不会来回跳动。

## 对条目做决定

您可以对条目进行**计划**、**忽略**、**完成**或**重新打开**。每个决定都会追加到条目的历史中，不会覆盖或删除任何内容。

## 忽略发现不会修改审计

把某条审计发现作为误报忽略后，它会从清单中移除。审计报告本身不变，这条发现仍按原样保留在报告中。

## 将发现标记为已修复

完成修改后，把该审计发现标记为已修复。决定按每条发现分别保存，后续审计不会重置它们。如果后续审计仍发现同样的问题，该条目会被标记为“标记为已修复后仍被检测到”，而不是悄悄保持关闭。

## 重新检测

重新检测只适用于审计发现。它会先显示用量预览，运行时消耗您月度额度中的一次审计，和您自己发起审计一样。

## 查看免费

打开清单或条目历史只读取已保存的数据，不会调用供应商，也不会消耗任何单位。
