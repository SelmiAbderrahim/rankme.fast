# Скачивание и публикация отчётов

RankMeFast экспортирует неизменяемую копию открытого отчёта. Файл и публичная ссылка на этот снимок сохраняют фильтры, даты источников, метки, язык и оформление. Экспорт не запускает новый запрос к поставщику и не расходует кредиты.

## Скачать отчёт

1. Откройте завершённый отчёт или сохранённый результат.
2. Выберите период, строки, движок, устройство, регион или разделы.
3. Нажмите **Скачать или поделиться** и выберите доступный формат.
4. Повторная загрузка находится в **Экспорт → Загрузки**.

Меню показывает только подходящие форматы. Если выбранный объём нельзя представить целиком, RankMeFast откажет и предложит сузить фильтры либо выбрать CSV/JSON. Строки никогда не отбрасываются молча.

## Форматы по типам отчёта

Эти идентификаторы составляют полный каталог и также записываются в версионированный JSON.

| Форматы | Типы отчёта |
|---|---|
| PDF, CSV, JSON | `audit.run`; `ranks.current`; `ranks.history`; `ranks.serp_features`; `google.gsc_search`; `google.gsc_sitemaps`; `google.gsc_generative_appearance`; `google.ga4`; `keyword.research_result`; `keyword.trends_run`; `keyword.ai_cluster_run`; `keyword.serp_cluster_run`; `keyword.cannibalization`; `backlinks.deep_run`; `backlinks.gap_run`; `backlinks.toxicity_run`; `competitors.organic`; `competitors.tech_stack`; `competitors.traffic_snapshot`; `competitors.traffic_comparison`; `competitors.content_run`; `competitors.landscape_run`; `actions.plan`; `ai.visibility`; `audience.research_run`; `brand.radar_scan`; `content.inventory_run`; `internal_links.run`; `local.seo_snapshot`; `local.reviews`; `local.geogrid_scan`; `pages.performance`; `app.keyword_tracking`; `app.research_result` |
| PDF, JSON | `client.composite`; `backlinks.summary`; `content.recommendation_outcome`; `weekly_pulse.run` |
| PDF, JSON, Markdown | `content.analysis`; `content.brief` |
| CSV, JSON | `backlinks.inventory`; `content.monitor_feed` |
| JSON, JSON-LD | `schema.generation` |
| Простой текст | `backlinks.disavow` |

PDF предназначен для чтения и презентации. CSV доступен только для табличных данных. JSON сохраняет полный версионированный документ. Markdown, JSON-LD и disavow-текст доступны только для отчётов, которые естественно их создают.

## Фильтры, периоды и даты источников

Снимок запоминает текущий выбор. История позиций сохраняет выбранные ключи и период; отчёт по отзывам — источник, рейтинг, запрос и даты. Каждое представление содержит дату или диапазон наблюдения и отделяет наблюдения, производные значения, оценки и сгенерированный текст. Последующее изменение экрана не меняет снимок.

## Брендинг и white label

PDF и публичные страницы по умолчанию оформлены как RankMeFast. Аккаунт с уже доступным white-label PDF может применить сохранённые название, цвет и логотип. CSV, JSON, Markdown, JSON-LD и текст не имеют визуального брендинга, но сохраняют режим в метаданных. Экспорт не расширяет тариф.

## Публичные ссылки

Если отчёт допускает публикацию, выберите **Поделиться**, разрешённые форматы и срок от одного до 90 дней. По умолчанию — 30 дней; ссылка не живёт дольше снимка. Скопируйте её при показе: RankMeFast не хранит читаемую ссылку для повторного отображения.

Любой, у кого есть ссылка, может открыть её без входа. Страницы имеют noindex и no-store, но получателей всё равно следует выбирать внимательно. Ссылка немедленно отзывается в **Экспорт → Общие ссылки**. Истёкшая, отозванная или потерявшая источник ссылка возвращает одинаковый ответ «не найдено».

## Конфиденциальность и внешнее использование

Экспорт может содержать URL, запросы, отрывки, позиции, отзывы, собственную аналитику и брендинг клиента. Передавайте его только тем, кто вправе видеть исходный отчёт. RankMeFast хранит разрешённый снимок и хеш содержимого, но не учётные данные поставщика, cookies, исходные токены ссылок или платёжные данные. Снимки истекают через 90 дней и блокируются сразу после удаления сайта или аккаунта; физическая очистка выполняется позже.

CSV использует UTF-8. Ячейки с формульным префиксом (`=`, `+`, `-`, `@`, табуляция или возврат каретки, в том числе после пробелов) помечаются как текст до CSV-экранирования. Не удаляйте этот префикс в Excel или Sheets.

JSON сейчас содержит `schemaVersion: 1` и отдельный `kindVersion`. Проверяйте оба поля и отклоняйте неизвестные версии. Не полагайтесь на внутренние ID или имя файла.

Файлы disavow, Markdown и JSON-LD перед использованием должен проверить человек. RankMeFast не отправляет disavow в Google, не публикует Markdown и не разворачивает JSON-LD за вас.
