# 链接情报

当普通反向链接概览不够详细时，请使用链接情报。你可以获取引荐域名、锚文本、历史或批量域名排名，也可以将自己的网站与最多三个竞争对手进行比较。

## 一个单位包含什么

- 每次提交的深度查询使用一个 `link_intel_checks` 单位。
- 链接差距分析按竞争对手计费。比较三个竞争对手会使用三个单位。
- 预览会显示准确的单位明细，但不会产生用量。确认运行时会再次检查余额。

请在[定价](./pricing.zh.md)中查看当前方案限额和用量包价格。深度工具需要符合条件的方案；重新打开已有结果只会读取已存储的数据。

## 缓存和退还规则

从缓存返回的结果仍会计入用量。成功但没有返回任何行的检查也会计入，因为它确认当时没有找到匹配链接。

如果数据源在 RankMeFast 保存任何一行之前失败，对应单位只退还一次。在多竞争对手分析中，每个竞争对手单独结算：有用的结果仍计费，失败且没有保存任何数据的部分会退还。预览、取消预览和读取已存储结果都不使用单位。

## 如何解读结果

深度结果会标明观察时间。如果没有首次发现日期，就保持“不可用”，不会编造。差距百分比根据已存储的行计算，并保留你输入竞争对手的顺序。

这些检查是**按需运行**，不是持续监控。需要更新的数据时请重新运行。关闭该功能会阻止新的预览和检查，但已存储的结果仍可读取。

## 开始检查

打开网站的反向链接工作区，选择**域名**、**锚文本**、**历史**或**差距**，查看用量预览后确认。你可以从运行列表重新打开旧结果，而无需再次消耗单位。

月度限额、用量包和通用退还规则请参阅[方案、限额与额度](./plans-limits-credits.zh.md)。
