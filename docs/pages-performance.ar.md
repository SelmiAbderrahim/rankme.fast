# أداء الصفحات

افتح موقعاً واختر **الصفحات** لمقارنة أداء البحث بمخزون أحدث عملية زحف. تقرأ العلامة البيانات المخزنة عند فتحها، ولا تجمع بيانات جديدة إلا عند اختيار **تحديث** أو **جمع بيانات احتياطية**.

## اختيار المصدر

يستخدم RankMeFast بيانات Google Search Console عندما تغطي الخاصية المتصلة الموقع. يبقى Search Console هو المصدر الرئيسي حتى أثناء المزامنة الأولى أو عندما لا تحتوي النافذة المختارة على صفوف. لا يستبدل RankMeFast مصدر Search Console صالحاً وفارغاً بتقديرات احتياطية.

إذا لم يكن Search Console متصلاً، أو احتاج إلى إعادة ربط، أو أُلغي الوصول، أو لم تطابق الخاصية الموقع، يمكن للعلامة استخدام أحدث لقطة كلمات مرتبة مخزنة. يوضح الاسم إن كانت اللقطة من DataForSEO أو بيانات تجريبية. وإذا لم توجد بيانات مخزنة من أي مصدر، تعرض العلامة الإجراء المناسب.

## المقاييس والنوافذ الزمنية

النقرات ومرات الظهور ونسبة النقر إلى الظهور ومتوسط الموضع في Search Console مقاييس ملحوظة لنافذة متحركة من 7 أو 28 أو 90 يوماً. يتأخر إبلاغ Google ثلاثة أيام، وقد يطبق Search Console أخذ عينات أو حداً للصفوف. راجع ملاحظة التغطية قبل مقارنة الإجماليات.

الموضع وحجم البحث والصعوبة وعدد الكلمات المرتبة والزيارات المقدرة في المصدر الاحتياطي هي تقديرات من لقطة زمنية واحدة. لا يوفر المصدر الاحتياطي نقرات أو مرات ظهور أو نسبة نقر، لذلك تظهر **غير متاحة** حتى عندما يكون مقياس آخر صفراً حقيقياً. تغيير النافذة يغير سياق السجل والمقارنة ولا يغير مقاييس اللقطة الرئيسية.

تقارن عبارة **منذ المزامنة السابقة** اللقطة الحالية بآخر لقطة ناجحة مؤهلة، وليست مقارنة بفترة سابقة. افتح صفحة لرؤية استعلامات Search Console أو الكلمات الاحتياطية المرتبطة وما يصل إلى 90 نقطة سجل مخزنة.

## الفرص وسياق الزحف

- **قريب من التقدم** يعني أن الموضع أعلى من 3 ولا يتجاوز 20، وأن الطلب يحقق حد القاعدة.
- **نسبة نقر منخفضة** تخص صفوف Search Console فقط عند توفر مرات ظهور كافية وموضع ضمن أول عشرة.
- **متراجع** و**فائز** يقارنان الموضع أو النقرات الملحوظة بالمزامنة الناجحة السابقة.
- **ظاهر لكنه غير قابل للزحف والفهرسة** يعني وجود أداء بحث بينما صنف أحدث زحف الصفحة على أنها غير قابلة للفهرسة.
- **غير مقاسة** تعني أن الزحف وجد صفحة قابلة للفهرسة لكن مصدر الأداء لا يحتوي على صف لها.

قابلية الفهرسة بالزحف تصف ما وجده RankMeFast أثناء الزحف، ولا تثبت أن Google فهرس عنوان URL. تبقى الصفحة الظاهرة لدى المصدر وغير القابلة للفهرسة في القائمة حتى يمكنك فحص التعارض.

## تكلفة التحديث والبيانات القديمة

يعيد تحديث Search Console استخدام مزامنته ولا يستهلك بحثاً عن كلمة مفتاحية. يستهلك تحديث المصدر الاحتياطي عملية بحث واحدة حتى عند إصابة ذاكرة التخزين المؤقت. فتح التفاصيل والبحث والتصفية والفرز والتنقل بين الصفحات تقرأ البيانات المخزنة فقط ولا تستهلك من حصتك.

إذا فشل التحديث، تبقى آخر لقطة ناجحة ظاهرة مع علامة قديمة. وقد تصبح اللقطة الاحتياطية قديمة بعد انتهاء نافذة حداثة ذاكرة الكلمات المرتبة.

## الحذف والتصدير

يؤدي حذف الموقع أو إكمال طلب حذف الحساب إلى إزالة لقطات الصفحات المخزنة. لا يتضمن تصدير الحساب الحالي لقطات الصفحات أو سجل Search Console وتتبع الترتيب عبر الزمن، لذلك لا تستخدمه كنسخة احتياطية لهذه الاتجاهات.

## استكشاف الأخطاء

- عند **المزامنة**، انتظر أول جمع من Search Console ثم حدّث العرض.
- عند طلب **إعادة الربط**، أصلح اتصال Google من علامة Google.
- عند عدم تطابق الخاصية، اختر خاصية تغطي بادئة URL أو نطاق الموقع.
- عند عدم وجود مصدر مخزن، اربط Search Console أو ابدأ الجمع الاحتياطي المدفوع بالوحدات.
- عند بلوغ الحد، راجع استخدام عمليات البحث أو الخطة. تبقى اللقطات المخزنة قابلة للقراءة.
- عند عدم التوفر، أعد محاولة المصدر نفسه. لا ينتقل RankMeFast سراً عن Search Console الصالح.
