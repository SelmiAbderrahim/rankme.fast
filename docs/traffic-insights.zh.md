# 流量洞察

流量洞察会为竞争对手域名创建已存储的快照，包括模型化月度自然访问量、域名排名、关键词数量、主要国家和历史。它适合方向性比较，不能替代竞争对手的真实分析数据。

## 一个单位包含什么

每个确认提交的目标域名快照使用一个 `traffic_snapshots` 单位。多域名预览会按域名显示单位，但每个确认的域名都会成为独立快照。预览或取消预览都不会产生用量。

当前月度限额和用量包价格请查看[定价](./pricing.zh.md)。打开、筛选或比较已有快照不会使用新单位。

## 每个数字都是估算值

所有数值字段都标有**估算**。这些数值根据搜索数据索引建模，不是真实的访问量、转化或分析数据。缺失值保持“不可用”。如果某一部分成功，部分完成的快照仍可能有用，界面会明确显示其状态。

比较视图最多对齐五个已存储快照，不会补齐或推断缺失的国家或历史数据。

## 缓存和退还规则

来自缓存的快照仍计作一个单位，成功但为空的结果也一样。

一个快照会收集多个相关观察。如果所有观察都失败，而且 RankMeFast 没有保留结果，该单位只退还一次。只要保留了任何可用观察，快照会以部分或完整状态存储，单位仍被消耗。重试不会重复退还。

## 何时更新

流量洞察是**按需运行**，不会持续监控竞争对手。需要更新估算时请创建新快照。如果运营方暂停新请求，已有列表、详情和比较仍可读取。

打开网站的**流量**标签，输入公开域名，查看用量预览后确认。限额、用量包和退还规则请参阅[方案、限额与额度](./plans-limits-credits.zh.md)。
