# Keyword-Intelligenz

In der Keyword-Intelligenz führen Sie Keyword-Gaps, Überblicke, Trends und KI-Clustering aus. Sie ist in den Plänen Pro und Agency enthalten.

## Was jeder Check kostet

- **Gap** vergleicht Ihre Domain mit Wettbewerbern und verbraucht eine `keyword_lookups`-Einheit pro Wettbewerber. Duplikate werden vorher entfernt.
- **Überblick** verbraucht eine `keyword_lookups`-Einheit pro nachgeschlagenem Keyword.
- **Trends** verbraucht eine `keyword_lookups`-Einheit pro Keyword.

Ein Ergebnis aus dem Cache zählt trotzdem als eine Einheit. Caching hält die Anbieterkosten und damit Ihren Preis niedrig, aber ein Check bleibt ein Check.

## Die Labels lesen

Jede Zahl hat ein Label, das zeigt, woher sie kommt:

- **Schätzung**: mit einfacher Rechnung aus Anbieterdaten ermittelt, etwa eine Trendlinie aus Monatsvolumen.
- **Anbieter-Beobachtung**: ein Wert, den der Datenanbieter gemeldet hat. Wir zeigen ihn unverändert.
- **KI-Interpretation**: von einem KI-Schritt erzeugt, etwa Cluster-Namen. Verstehen Sie sie als Vorschlag.

## Clustering

Clustering sortiert eine Keyword-Liste in einem einzigen KI-Schritt nach Themen. Jeder Lauf verbraucht eine `ai_summaries`-Einheit. Führen Sie genau dieselbe Liste noch einmal aus, bekommen Sie das gespeicherte Ergebnis kostenlos.

## Wenn die Keyword-Lookups aufgebraucht sind

Das Credit-Paket `keywords-1k` fügt einmalig 80 `keyword_lookups` für 19 $ hinzu. Damit laufen Gap-, Überblick- und Trends-Checks weiter, wenn Ihr Monatskontingent verbraucht ist. Siehe [Pläne, Limits & Credits](./plans-limits-credits.de.md).

## Von Clustern zur Arbeit

Wenn Sie ein Cluster annehmen, geht es dorthin, wo das Cluster es vorschlägt: in ein Content-Intelligence-Briefing oder in Ihre SEO-Arbeit. Verwerfen speichert nur Ihre Entscheidung und ändert sonst nichts. Jede Entscheidung bleibt erhalten.
