# Erste Schritte

RankMeFast zeigt Ihnen, wie gut Ihre Website Besucher aus Google und aus KI-Assistenten gewinnt.

## 1. Konto erstellen
Registrieren Sie sich per E-Mail oder mit Google. Der Bestätigungslink ist 24 Stunden gültig.

## 2. Website hinzufügen
Geben Sie die vollständige URL mit `https://` ein. Die Website muss öffentlich und erreichbar sein.

## 3. Ersten Audit starten
Klicken Sie auf **Ersten Audit starten**. Das dauert ein bis drei Minuten. Die Monatslimits der Bezahlpläne stehen unter [Pläne, Limits & Credits](./plans-limits-credits.de.md).

## 4. Die drei Tabs
- **Jetzt beheben**: Probleme, auf die Google am schnellsten reagiert. Fangen Sie hier an.
- **Beobachten**: kleinere Punkte oder Prüfungen, für die noch nicht genug Daten vorliegen.
- **Bestanden**: alles, was Ihre Website erfüllt.

Mehr dazu unter [Ihr Audit-Bericht](./audit-report.de.md).

## 5. Empfohlene nächste Schritte
- Verbinden Sie die Google Search Console, siehe [Google Search Console verbinden](./google-search-console.de.md).
- Fügen Sie ein paar Keywords zum Tracking hinzu, siehe [Ranking-Tracking](./rank-tracking.de.md).
