# Content-Briefings

Ein Briefing entsteht für ein verfolgtes Keyword. RankMeFast nimmt die gespeicherten Top-10-Ergebnisse plus bis zu zehn Seitenabrufe und macht daraus eine Gliederung und ein Fragenset, an dem Sie schreiben können.

## Was ein Briefing enthält

Am Anfang stehen einfache Statistiken über die abgerufenen Seiten:

- Spanne und Durchschnitt der Wortzahl
- ein Histogramm der Überschriften
- die strukturierten Datentypen, die die Seiten deklarieren

Danach schreibt die KI-Laufzeit eine Gliederung und ein Fragenset.

Jeder Gliederungspunkt und jede Frage muss etwas Geliefertes zitieren: ein gespeichertes Dokument, eine der Statistiken, eine „Ähnliche Fragen“-Zeile oder einen Clusterbegriff.

Kann ein Punkt oder eine Frage keinen Beleg nennen, wird er entfernt. Das Briefing lässt lieber eine Lücke, als eine Quelle zu erfinden.

## Entwurf und Neubewertung

Der Entwurfseditor bewertet Ihren Text anhand derselben Statistiken, aus denen das Briefing entstanden ist. Ändert sich der Wert, sehen Sie also, warum. Eine verborgene Modellmeinung steckt nicht dahinter.

Die Neubewertung nutzt die gespeicherten Statistiken und kostet keine weitere Einheit. Ein Briefing kostet eine Einheit, gleich ob das SERP aus dem Speicher oder aus einer frischen Prüfung stammt.

## Auf das Datum achten

Die Statistiken beschreiben genau die Seiten, die an einem bestimmten Datum abgerufen wurden, und dieses Datum steht daneben. Lesen Sie sie als Momentaufnahme, nicht als dauerhaftes Bild „der Top 10“.

## Verfügbarkeit

Briefings gehören zum Agency-Tarif. In Pro erhalten Sie sie über das Guthabenpaket `content-briefs-10`, Starter hat kein Briefing-Kontingent. Einheiten und Tarifgrenzen finden Sie unter [Preise](./pricing.de.md).

Ein Briefing ist eine Hilfestellung. Es schätzt nicht Ihre Rankingchancen, und RankMeFast veröffentlicht nie etwas auf Ihrer Site.
