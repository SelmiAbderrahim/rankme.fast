# Самостоятельный хостинг RankMeFast

## Перед началом

Установите Docker с Compose и скачайте исходный код проекта. Выполняйте команды из каталога проекта. Программа бесплатна; сервер и API провайдеров оплачиваете вы. Не раскрывайте файл окружения.

## Настройте установку

Скопируйте шаблон и отредактируйте корневой `.env`:

```bash
cp .env.example .env
```

Задайте `CLIENT_URL` и `SERVER_URL`. Для `BETTER_AUTH_SECRET` и `MASTER_ENCRYPTION_KEY` нужны отдельные случайные значения: выполните `openssl rand -hex 32` по одному разу для каждого. Затем настройте реальные провайдеры, их ключи и отправку почты, как описано в `.env.example`. Для своей установки можно оставить `PAYMENT_PROVIDER=none`.

Если всё работает на одном адресе, задайте для `APP_URL` и `VITE_SITE_URL` то же значение, что и для `CLIENT_URL`.

Не запускайте систему с ключами-заглушками. В рабочем режиме имитация провайдеров по умолчанию запрещена, а демонстрационные исключения не стоит включать на публичном сервере.

## Запустите и проверьте

После настройки запустите платформу и убедитесь, что все сервисы работают:

```bash
docker compose up -d --build
docker compose ps
```

Затем откройте адрес из `CLIENT_URL`, создайте аккаунт и добавьте первый сайт.

## Поддерживайте работу

Безопасность сервера, HTTPS, обновления и резервные копии баз данных и файла окружения — на вас. Делайте копию перед каждым обновлением. Если запуск не удался, проверьте журналы сервисов и не публикуйте журналы с учётными данными.
