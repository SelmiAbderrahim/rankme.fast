# استضافة RankMeFast بنفسك

## قبل البدء

ثبّت Docker مع Compose واحصل على ملفات المشروع. نفّذ الأوامر التالية من مجلد المشروع. البرنامج مجاني، وتدفع أنت تكاليف الخادم واستخدام واجهات المزوّدين. احتفظ بملف البيئة سريًا.

## تهيئة التثبيت

انسخ القالب ثم عدّل ملف `.env` في الجذر:

```bash
cp .env.example .env
```

اضبط `CLIENT_URL` و`SERVER_URL` لنشرك. يحتاج كلٌّ من `BETTER_AUTH_SECRET` و`MASTER_ENCRYPTION_KEY` قيمة عشوائية خاصة به؛ شغّل `openssl rand -hex 32` مرة لكل منهما. بعد ذلك هيّئ المزوّدين الفعليين وبيانات اعتمادهم ونقل البريد كما يوضح `.env.example`. يمكن إبقاء الفوترة على `PAYMENT_PROVIDER=none` لتثبيتك الخاص.

للتثبيت على أصل واحد، اضبط `APP_URL` و`VITE_SITE_URL` على قيمة `CLIENT_URL` نفسها.

لا تبدأ ببيانات اعتماد مؤقتة. يرفض وضع الإنتاج المزوّدين الوهميين افتراضيًا، ولا ينبغي تفعيل تجاوزات العرض التجريبي في نشر عام.

## التشغيل والتحقق

بعد التهيئة، شغّل المنظومة وتأكد من أن كل الخدمات سليمة:

```bash
docker compose up -d --build
docker compose ps
```

ثم افتح العنوان الذي عيّنته في `CLIENT_URL`، وأنشئ حسابًا وأضف موقعك الأول.

## متابعة التشغيل

أنت مسؤول عن أمن الخادم وHTTPS والتحديثات والنسخ الاحتياطية لقواعد البيانات وملف البيئة. خذ نسخة احتياطية قبل كل تحديث. إذا فشل التشغيل فافحص سجلات الخدمات، ولا تنشر سجلات تحتوي على بيانات اعتماد.
