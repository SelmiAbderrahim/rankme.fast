# 反向链接与竞品分析

反向链接与竞品分析解决不同的问题。反向链接显示哪些网站链接到某个域名。竞品分析则比较你为自有网站确认的竞品所覆盖的搜索词和排名页面。

## 网站工作区

打开一个网站并选择**竞品**。竞品组合、关键词版图、内容比较、监测、流量估算和已保存报告都在这个工作区。Pro 每份报告最多可选三个已确认竞品，Agency 最多可选十个。每个网站最多保留十个活跃竞品。

Starter 会看到升级说明。如果运营人员暂停新任务，已保存报告仍可阅读。方案变更后，现有数据也可能保留为只读状态。

## 额度与确认

每选择一个竞品，关键词版图报告会消耗一个 `keyword_lookups` 额度。比较三个竞品会消耗三个额度。确认前，RankMeFast 会显示这份报告将使用多少额度和行数。缓存命中也会计入。竞品发现刷新是可选操作，需要单独预览和确认，并额外消耗一个 `keyword_lookups` 额度。

系统会为每个竞品执行三项关键词查询：双方共有、仅你的网站有排名、仅竞品有排名。每项查询最多保留 100 行，所以包含十个竞品的 Agency 报告最多有 3,000 行关键词数据。

## 阅读关键词版图

报告使用五种分类：

- `missing`：竞品有排名，而你的站点未被观测到。
- `owned_only`：你的站点有排名，而竞品未被观测到。
- `shared_behind`：双方都有排名，你的名次更低。
- `shared_ahead`：双方都有排名，你的名次更高。
- `shared_even`：双方观测到的名次相同。

排名、排名 URL 和观测日期直接来自数据源。搜索量和难度是数据提供方的估算。分类、可信度和建议根据报告中保存的数据得出。缺失值会保持缺失，不会用猜测补齐。部分完成的报告会说明有多少竞品和来源步骤返回了可用数据。

## 排名页面与内容

Agency 报告可以建议排名页面配对。开始内容比较前，请检查双方 URL。你可以把建议的竞品 URL 换成同一已确认域名下的其他公开 URL。建议本身不会启动抓取，RankMeFast 也不会悄悄换成首页。

确认后的内容比较会单独消耗一个 `competitor_content_runs` 额度。审核页面配对不会消耗该额度。页面监测也需要单独操作和确认。

建议会留在报告中，直到你明确接受。接受后，“后续操作”中会新增一条事项，但不会发布内容或启动其他付费任务。

## 已保存报告与导出

重新打开关键词版图或历史内容任务不会调用数据提供方，也不会再次消耗额度。PDF、CSV 和 JSON 导出都读取已保存快照。选择超过 1,000 行时，PDF 会拒绝生成并提示使用 CSV 或 JSON。这两种格式会在 3,000 行报告上限和统一下载大小限制内保留完整选择。

旧的竞品书签会打开“竞品”标签页。Content Intelligence 的旧竞品链接会打开“内容”视图。独立的 Keyword Gap 会保留原有历史记录，并继续按每个竞品一个 `keyword_lookups` 额度计费。

反向链接评分和流量数字都受数据提供方覆盖范围影响，属于估算。请比较同一来源和日期的观测结果，不要把它们当作你自己的分析数据。
