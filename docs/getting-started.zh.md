# 入门指南

RankMeFast 帮您了解网站从 Google 和 AI 助手获取访客的情况。

## 1. 创建账号
用邮箱或 Google 注册。如果两分钟内没收到验证链接，请查看垃圾邮件。

## 2. 添加网站
输入完整 URL（含 `https://`）。网站必须公开且可以访问。我们只保留协议和主机部分。

## 3. 运行首次审计
点击 **运行首次审计**，通常需要一到三分钟。付费套餐的月度限额见[方案、限额与额度](./plans-limits-credits.zh.md)。

## 4. 阅读三个标签
- **立即修复**：Google 反应最快的问题，建议先处理。
- **关注**：较小的问题，或暂时缺少数据的检查。
- **已通过**：网站已达标的检查。

详见[阅读您的审计报告](./audit-report.zh.md)。

## 5. 建议的下一步
- 连接 Google Search Console，见[连接 Google Search Console](./google-search-console.zh.md)。
- 添加几个关键词用于追踪，见[关键词排名追踪](./rank-tracking.zh.md)。
