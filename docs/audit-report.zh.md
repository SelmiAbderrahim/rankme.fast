# 阅读您的审计报告

每次审计完成后，您会看到一个包含三个标签和 **重新检测** 按钮的报告。

## 三个标签
- **立即修复**：Google 反应最快的问题。
- **关注**：较小的问题，或数据不足的检查。
- **已通过**：已达标的检查。

## 每条问题包含什么
- **标题**：用直白的话说明问题。
- **为什么这很重要**：一句话说明影响。
- **受影响的网址**：发现该问题的页面。
- **如何修复**：需要做的修改，附复制按钮。

## 重新检测与变化标记
修复后点击 **重新检测**，可能出现两种标记：
- **已修复**：之前失败的规则现在通过了。
- **已退化**：规则在原本通过的地方出现失败。

## `llms.txt` 文件
一种较新的约定，用来告诉 AI 助手您希望它们引用哪些页面。我们把这条规则视为 **建议性**。

## 用简单的话解释每条规则
- **被 Google 屏蔽**：`robots.txt` 阻止了访问。
- **站点地图缺失或不完整**：添加 `sitemap.xml` 并在 `robots.txt` 中引用。
- **页面标题缺失或不佳**：每页独立标题，30–60 字符。
- **元描述缺失或重复**：每页独立描述。
- **H 标题使用不当**：每页仅一个 `<h1>`。
- **canonical 缺失或错误**：设置正确的 `<link rel="canonical">`。
- **结构化数据缺失**：添加合适的 JSON-LD。
- **内部链接失效**：修复或删除错误链接。
- **内容过少**：页面少于约 200 字。
- **未发现 FAQ 信号**：合适时添加常见问题区块。
- **缺少 llms.txt（建议性）**：一种面向 AI 爬虫的较新约定。
- **未强制 HTTPS**：将 http 重定向到 https。
- **真实访客体验较差**：Chrome UX 数据显示加载缓慢。
- **实验室性能评分低**：Lighthouse 单次运行波动较大。
- **移动端体验不佳**：检查 viewport 与点击目标大小。
- **未被 Google 索引**：Google 未将页面纳入索引。
- **富媒体结果有问题**：结构化数据存在错误。
- **已索引但有警告**：Canonical/重复内容信号。
