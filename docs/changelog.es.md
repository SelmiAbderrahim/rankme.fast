# Registro de cambios

## 29 de julio de 2026: Nuevas herramientas, sin cambios de precio para suscripciones existentes

Hemos añadido [Inteligencia de enlaces](./link-intelligence.es.md), [Información de tráfico](./traffic-insights.es.md), [Tendencias de palabras clave](./keyword-trends.es.md), [Inteligencia de reseñas](./review-intelligence.es.md) y [Radar de marca](./brand-radar.es.md).

Si ya tienes una suscripción, el precio actual de tu suscripción a RankMeFast no cambia. Los nuevos límites mensuales, el complemento opcional de Radar de marca y los paquetes de un solo pago se aplican como se explica en [Precios](./pricing.es.md). Solo pagas un complemento o paquete si decides comprarlo.

No vamos a trasladarte a otro plan y no necesitas hacer nada. Tus informes e historiales guardados siguen disponibles según las reglas de tu plan actual.
