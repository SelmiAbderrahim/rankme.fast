我们新增了[链接情报](./link-intelligence.zh.md)、[流量洞察](./traffic-insights.zh.md)、[关键词趋势](./keyword-trends.zh.md)、[评论洞察](./review-intelligence.zh.md)和[品牌雷达](./brand-radar.zh.md)。

我们不会把你迁移到其他方案，你也不需要采取任何操作。已有报告和历史仍按当前方案规则提供。
