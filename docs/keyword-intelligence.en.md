# Keyword Intelligence

Keyword Intelligence is where you run keyword gaps, overviews, trends and AI clustering. It's available on the Pro and Agency plans.

## What each check costs

- **Gap** compares your domain with competitors. It uses one `keyword_lookups` unit per competitor, after duplicates are removed.
- **Overview** uses one `keyword_lookups` unit per keyword you look up.
- **Trends** uses one `keyword_lookups` unit per keyword.

A result served from cache still counts as one unit. Caching keeps vendor costs, and so your price, down, but each check is still a check.

## Reading the labels

Every number has a label that says where it came from:

- **Estimate**: worked out with simple arithmetic from provider data, such as a trend line calculated from monthly volumes.
- **Provider observation**: a value the data provider reported, shown as we received it.
- **AI interpretation**: produced by an AI step, such as cluster names. Treat it as a suggestion.

## Clustering

Clustering sorts a keyword list into topics in one AI step. Each clustering run uses one `ai_summaries` unit. If you rerun the exact same list, you get the saved result for free.

## When keyword lookups run out

The `keywords-1k` credit pack adds 80 `keyword_lookups` for a one-time $19. It covers gap, overview and trends checks once your monthly allowance is used up. See [Plans, limits & credits](./plans-limits-credits.en.md).

## From clusters to work

When you accept a cluster, it goes where the cluster suggests: into a Content Intelligence brief or into your SEO work. Dismissing a cluster records your decision and changes nothing else. Every decision is kept.
