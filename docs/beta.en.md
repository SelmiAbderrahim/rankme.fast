# Public beta

RankMeFast is in public beta. You can use it for real work, but expect some rough edges while we finish it.

## What works today

The core flows work: running a site audit, reading the report, and tracking keyword rankings over time. Plans and billing are live.

## What is still rough

Some screens are still being finished. Wording and layout can change between releases, and you may hit an error we haven't seen yet. If something looks wrong, tell us.

## Report a bug

Use **Report a bug** in the beta banner at the top of the page. Once the source code is public, it opens a GitHub issue form. Until then, it starts an email to support@rankme.fast, which also works if you hid the banner.

A useful report says:

- what you were trying to do
- what you expected, and what happened instead
- the page address and your browser
- a screenshot, if you can take one

Leave out passwords, API keys, and other secrets. We read every report, but we can't promise a response time during the beta.
