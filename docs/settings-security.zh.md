# 账户安全

在 **设置 → 安全**（网址：`/settings/security`）中管理保护您 RankMeFast 账户的凭据。

## 更改密码

1. 登录并打开 **设置 → 安全**。
2. 填写您的 **当前密码**，然后设置 **新密码** 并进行确认。新密码至少八位，且必须与当前密码不同。
3. 点击 **更新密码**。

我们使用 scrypt 保存密码哈希，因此我们永远看不到您的明文密码。密码更改成功后：

- 账户的所有 **其他** 活动会话会被登出。您用于更改密码的设备保持登录状态。
- 我们会向您的账户邮箱发送一封确认邮件。如果不是您本人修改的密码，这封邮件就是提示——请立即通过[忘记密码流程](./getting-started.zh.md)重置密码。

如果当前密码不正确，我们会在输入框旁提示，但绝不会透露某个邮箱是否已注册。

## 更改邮箱

1. 登录并打开 **设置 → 安全**。
2. 在 *更改邮箱* 卡片中输入 **新邮箱** 地址，必须与当前邮箱不同。
3. 点击 **发送验证链接**。

我们会向 **新** 邮箱发送一封确认邮件。只有在您点击该链接后，账户邮箱才会更新：

- 在您完成确认之前，**当前邮箱仍可用于登录**。
- 如果新邮箱已经绑定到其他账户，我们会以一条通用的 *邮箱不可用* 消息拒绝更改，不会透露该邮箱的归属。
- 该链接只可使用一次并会在短时间内过期；如已过期，请从同一页面重新发起更改。

## 忘记当前密码？

如果不记得当前密码，请先登出，然后在登录界面点击 **忘记密码？**。邮件中的链接会将您带到一个页面，您可以在无需确认旧密码的情况下设置新密码。


## 双因素身份验证

在登录时添加第二步，让被盗的密码无法单独进入您的账户。

### 启用

1. 登录并打开**设置 → 安全**。
2. 在**双因素身份验证**卡片中，输入当前密码并点击**启用**。
3. 使用 1Password、Authy 或 Google Authenticator 等身份验证应用扫描二维码，或将手动输入代码粘贴到应用中。
4. 复制或下载**备用代码**。每个代码只能使用一次，它们是丢失设备时唯一的登录方式。
5. 输入身份验证应用当前显示的六位数字代码并点击**验证并启用**。

### 关闭

打开同一卡片，点击**关闭**，然后输入当前密码。

### 管理员账户

如果您的账户拥有**管理员**角色，则必须启用双因素身份验证。启用前无法打开管理面板。

### 设备丢失

在验证屏幕使用备用代码，屏幕上有**使用备用代码**链接。若备用代码用完，团队管理员可从管理面板重置第二因素。

## 数据权利

您可以申请导出或删除账户数据。当前导出仅限生成文件中的数据集，不包含页面快照，也不包含 GSC 和排名追踪的时间序列历史。删除范围更广：宽限期结束后，即使某些已存账户数据不在导出范围内，也会被删除。您可以在宽限期内取消删除请求。页面数据的保留规则请参阅[页面表现](./pages-performance.zh.md)。
