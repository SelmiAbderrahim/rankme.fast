## Why

The self-hosted edition is a hard fork of the cloud codebase. It was seeded from cloud commit `e0316397` (2026-09-23) with billing, plans, credits, usage limits, Polar, the landing page and every marketing page removed. Since then the cloud repo has gained about 136 commits of fixes and features (rank-check jobs and one rank status model, bulk keyword add and bulk rank checks, deep-crawl audit signals, finding triage, the mobile app shell and site navigation, session hardening, pluralization, RTL/bidi, responsive tables, and much more). The OSS repo has 94 commits of its own, and many of them fix the same user-facing problems in a different way.

Goal: bring every portable cloud change into OSS, reconciled with the OSS fixes, with nothing billing- or marketing-shaped coming back, and every quality gate green.

Note on the seed: the OSS seed is `e0316397`, **not** `1b48560d`. `f80f93a8` and `39df0c83` (merged later via `1f0a19ca`) are not in OSS and are in scope.
